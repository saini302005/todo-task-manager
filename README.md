# 📝 To-Do Task Manager

A simple, responsive and interactive **To-Do Task Manager** built using HTML, CSS and JavaScript.

This project helps users create, manage, edit, complete and delete daily tasks. Tasks are stored in the browser using **Local Storage**, so they remain available even after refreshing the page.

## 📌 Project Overview

The To-Do Task Manager is a beginner-friendly JavaScript project designed to demonstrate how a web application can manage dynamic data in the browser.

Users can:

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete individual tasks
- Filter tasks
- Clear all completed tasks
- Store tasks using Local Storage
- Use the application on desktop and mobile devices

---

## ✨ Features

### 1. Add Tasks

Users can enter a task and click the **Add Task** button.

Tasks can also be added using the **Enter** key.

---

### 2. Complete Tasks

Each task contains a checkbox.

When the checkbox is selected:

- The task becomes completed
- The task text gets a strike-through effect
- The completed state is saved in Local Storage

---

### 3. Edit Tasks

Users can edit an existing task.

The Edit feature provides:

- Edit input
- Save button
- Cancel button
- Enter key to save
- Escape key to cancel

---

### 4. Delete Tasks

Users can delete individual tasks using the **Delete** button.

---

### 5. Task Filters

The application provides three filters:

- **All** — Shows all tasks
- **Active** — Shows incomplete tasks
- **Completed** — Shows completed tasks

---

### 6. Clear Completed

The **Clear Completed** button removes all completed tasks at once.

A confirmation message is displayed before removing them.

---

### 7. Local Storage

Tasks are stored using the browser's Local Storage.

Therefore, tasks remain available after:

- Page refresh
- Browser restart

---

### 8. Responsive Design

The application works on:

- Desktop
- Laptop
- Tablet
- Mobile

The layout automatically adjusts according to screen size.

---

### 9. UI Animations

The project includes:

- Smooth hover effects
- Button animations
- Task appearance animation
- Container entrance animation
- Input focus effects
